# Independent Gaussian reference calculations

This directory contains validation code only. It imports Python standard-library modules, never either package or native fitting engine. `BlockModel` uses group means/within-group products and a one-dimensional concentrated variance-ratio search. `dense_reference` independently builds V and uses an independently coded dense Cholesky solve. The two routes compare ML, REML (including its determinant convention), GLS coefficients and every covariance entry at three fixed variance pairs for each valid fixture. ML is also checked at a deliberately non-GLS coefficient pair. Profile reference endpoints minimize the constrained ML scalar objective and solve the signed-root likelihood-ratio equation; an explicit finite search cap reports incomplete search rather than an infinite endpoint.

`python3 control/oracle/freeze_fixtures.py` deterministically reconstructs the 11 observations-only CSVs and their SHA256 manifest. It does not simulate or fit. It is a development reconstruction command, not permission to change frozen observations after outcomes are seen.

`python3 control/oracle/independent_gaussian.py --output control/oracle/reference.json` checks all 11 frozen fixtures, including two expected rejections, exact zero group-variance OLS limit, two-group REML group-variance nonidentification, and affine predictor/response transformations of the full covariance, coefficients, variances and likelihood convention.

`python3 control/oracle/independent_gaussian.py --profiles --output control/oracle/reference-with-profiles.json` also solves 32 independent endpoints: alpha/beta x lower/upper x .90/.95 x four datasets (`profile_validation=true`). An assertion requires each scalar root residual below 1e-8. Those are numerical roots under the chosen model, not calibrated confidence coverage.

To check a native result independently, import `read_data`, `BlockModel` and `dense_reference`. Evaluate `dense_reference(data,native_sigma2,native_tau2)` for its GLS C and full ML NLL; use `criterion="REML"` for restricted NLL. For a profile endpoint `b`, use `BlockModel(data).optimize(constraint=(column,b))` and subtract the independent unconstrained ML NLL from the same model, multiply by two and take the signed square root. Compare against the designated level's normal cutoff, and also compare to the independently rooted endpoint in the profile JSON. Use independent endpoint distance and root-LR residual thresholds frozen in CONTRACT.md; do not substitute the native spline for this acceptance check.

Its C/normal endpoints are not an engine-agreement target; independently reconstruct C at each native fit's own variances instead. `near_residual_collapse` is numerical stress, not a well-conditioned strict tolerance fixture. The two rejection fixtures require no accepted native fit.
