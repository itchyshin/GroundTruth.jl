## Objective and normal intervals

V = sigma2*I + tau2*Z*Z'. ML negative log likelihood is `(n*log(2*pi)+log|V|+r'V^-1*r)/2`. REML negative log likelihood uses the explicit determinant convention `((n-p)*log(2*pi)+log|V|+log|X'V^-1X|+y'P*y)/2`, p=2 and `P=V^-1-V^-1X*(X'V^-1X)^-1*X'V^-1`. Record this convention. Never order or compare ML and REML objective values as if they were the same criterion.

At either criterion's fitted variances the independent covariance is C=(X'V^-1X)^-1. Normal intervals are estimate +/- qnorm((1+level)/2)*sqrt(C[j,j]); they use normal rather than t quantiles and no extra residual-scale multiplication. Use the same covariance for both levels. Native vcov is a comparison target, never the sole oracle.

Alignment: alpha/intercept/column1; beta/x/column2; sigma2/residual variance/diagonal V; tau2/group variance/group-equality V block. Fixtures hold observations only; their named design purpose is not a claim that a fit recovers a generating truth.

## Profile, accepted point durability and states

Only ML fixed-effect likelihood-ratio profiles are requested. For coefficient b, independently constrained ML NLL minimizes over the other fixed coefficient and both variance components. The signed root likelihood ratio is sign(b-bhat)*sqrt(2*(NLL(b)-NLLhat)); its cutoff is qnorm((1+level)/2), equivalently LR cutoff chi-square(1,level). These asymptotic cutoffs do not establish small-sample calibration.

Before profiling, copy all accepted estimates, convergence/optimizer diagnostics, base objective, variances, warnings and normal covariance into an immutable-value snapshot. Profile a separate model/helper. Never re-extract points from a mutated model. Success, failure, timeout and partial output all return that snapshot unchanged. A profile exception does not reject an accepted base fit; true user interrupt retains the existing interrupt policy.

Profile endpoint states per target/level are finite, unbounded, incomplete, error, timeout or invalid. Runtime finite requires two finite ordered endpoints, native curve bracketing of the root-LR cutoffs, and a native forward-curve endpoint residual check. This runtime check is an internal curve-consistency check, not independent likelihood validation of an arbitrary future dataset. Unbounded requires actual evidence of an unbounded confidence set; a failed bracket, interpolation NA, missing row or exhausted search is incomplete/error, not unbounded. A finite one-sided bound with a mathematically established infinite opposite endpoint can be explicit unbounded with extended-real endpoints. Never place infinity in legacy usable intervals. Preserve completed target/level pairs that pass these runtime checks if a later pair fails, but mark all unfinished pairs explicitly. Report exception text and elapsed time, and never replace a profile with a normal interval under a profile label.

`profile_timeout` is a wall deadline for native profile work including helper startup, after the base fit is safely held by the parent. Native cached MixedModels profiling has no hard deadline and profiles variance parameters before fixed effects; a Julia task timeout alone cannot stop blocking native work. Use one bounded killable helper around native profiling, with no general scheduler. Parent terminates and waits/reaps that helper on timeout, success and errors; remove temporary transport files. R elapsed time limits alone cannot guarantee interruption of native code either. OS-specific hard timeout support must be stated; unsupported platforms fail explicitly while retaining points. Helper startup exceeding deadline is timeout. No detached/orphan process. Count helper engine loading inside the shared numerical allowance.

## Paired comparisons and Monte Carlo standard errors

Pair by exact scenario/replicate/target/level, require unique rows and the same attempted replicate set; do not compare independent denominators as paired. Let F_m indicate a finite validated interval and H_m indicate finite-and-covered (H=0 for every nonfinite/unusable/failure attempt). Report attempted n, per-method finite count, finite hits, finite-covered yield mean(H), conditional finite coverage sum(H)/sum(F), joint-finite count and all state counts. Conditional coverage is NA if sum(F)=0; no all-failed coverage zero.

Paired finite-covered yield difference m1-m0 is mean(H1-H0), MCSE=sd(H1-H0)/sqrt(n), sample sd, NA for n<2. Conditional finite coverage difference uses each method's own finite denominator, never the joint-finite subset: C_m=mean(H_m)/mean(F_m), influence psi_m=(H_m-C_m*F_m)/mean(F_m), paired MCSE=sd(psi1-psi0)/sqrt(n). Undefined if either finite denominator is zero or n<2. This is the first-order ratio/delta-method MCSE, not an exact small-sample interval. A separately labelled joint-finite comparison may be supplied but cannot replace these estimands. Truth, target and nominal level must agree. Report each separately at .90 and .95. No claim of simulation precision from Phase I.
